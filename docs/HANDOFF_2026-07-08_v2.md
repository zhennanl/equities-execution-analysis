## 3. CRITICAL OPERATING PROTOCOLS (encode real incidents — follow literally)

These EXTEND the original handoff's §2. The mount this repo lives on is
unreliable for file writes in specific ways discovered this session:

**P-A. The Edit tool truncated `order_ticket.py` once it crossed ~300 lines**
(the original P-1 incident, reproduced). **Do not use the Edit/Write host tools
on large files.** For any file > ~250 lines, patch via **bash-python with anchor
asserts**: read → `assert s.count(anchor)==1` for every anchor → `str.replace`
→ single `Path(...).write_text(...)`. Back up first: `cp file /tmp/backup_file`.
After: `wc -l`, `py_compile`, inspect `tail`.

**P-B. The Write/Edit host tools intermittently DESYNC from the bash mount.** A
`Write` reported success while `pytest`/`bash` still read the OLD bytes; a bash
`>>` append once interleaved and corrupted a test file. **Treat `bash cat > file`
(heredoc) and `python3 … write_text` as the AUTHORITATIVE write path.** Always
re-run `py_compile` + `pytest` via bash immediately after any write, and for test
files prefer full-file `cat >` rewrites over appends.

**P-C. git doesn't see edits to tracked files (frozen mtime).** After editing a
tracked file, `git status`/`git diff` may report it clean even though the content
changed (confirmed via `git hash-object` ≠ `git ls-files -s`). Fix:
`touch <file> && git update-index -q --really-refresh`. **Before ending any
session, `touch` every tracked file you edited and re-check `git status`**, or
the user won't see (and can't commit) your changes — this is exactly what caused
the partial-deploy incident.

**P-D. Stale `.git/index.lock`.** A `git status` can leave a 0-byte
`.git/index.lock` that the sandbox cannot `rm` ("Operation not permitted"). Clear
it with the Cowork file-delete permission tool (`allow_cowork_file_delete` then
`rm`). It blocks the user's commits until removed.

**P-E. Backward-compat invariant (from original P-4).** A default `OrderTicket()`
(now Buy, `locate_confirmed=True`) must reproduce pre-feature numbers EXACTLY;
`is_default()` short-circuits the constraint path. Add dataclass fields only at
the END with defaults. Tested by `test_agent3.py::test_default_ticket_reproduces
_no_ticket_exactly`.

**P-F. Side-aware invariant.** Signed costs = `side_sign(side) * raw`
(slippage/opportunity/tracking); market impact stays positive-adverse. The
mechanical guard is the **mirror-property test** (`test_sell_side.py`): a Sell on
price path P equals a Buy on `2·P0 − P`. Re-run it after touching any cost
arithmetic.

**P-G. P-8 network budget (original).** Keep live yfinance fetches to 1–2 per
session (5 were used across the whole 2026-07-08 day). Reuse the recorded fixture
(`tests/fixtures/AAPL_*`) for offline work; the sandbox can run the app's
fetchers but Yahoo rate-limits.
